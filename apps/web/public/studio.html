Turn drawings into geometry

Up to 6 sources / 16 MB per job. Start with one clear floor plan. No usable scale = no fabricated metric model. PDFs are sent whole; use small batches. Photos inform finishes, not hidden rooms.

No API key? Trace a calibrated floor locally

Use an authorised PNG/JPEG plan crop. For PDFs, export a plan page to an image first. Mark two points of a known dimension, then draw the outline. This builds only a floor slab and its perimeter walls; it does not invent the inside.
