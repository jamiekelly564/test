Set up AI on this PC

In the VS Code terminal, stop the app with Ctrl + C, then run npm run setup:ai. It asks privately for your API key and checks the selected model. Restart with npm run dev.

No key is entered on this webpage. Later AI searches and reconstruction have separate API costs. A model-access check is not a billing or accuracy test.
